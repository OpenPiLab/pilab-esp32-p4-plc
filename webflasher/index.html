Flash PiLab PLC from your browser

Install the current PiLab PLC firmware onto an ESP32-P4 board without installing ESP-IDF, Python, a compiler, or esptool locally.

Install firmware

Connect the PiLab PLC ESP32-P4 board over USB. Use a Chromium-based desktop browser such as Chrome, Edge, or Brave. Click the install button and select the board serial port.

View manifest
This browser may not support Web Serial. Use Chrome, Edge, or Brave on desktop. GitHub Pages uses HTTPS, which is required.

Before flashing

  1. Use a USB data cable, not a charge-only cable.
  2. Close serial monitors or other programs using the board.
  3. If auto-reset fails, hold BOOT, tap RESET, then release BOOT.
  4. For a first install, allow erase when prompted.

ESP32-P4 note

ESP32-P4 builds often use a different bootloader offset than older ESP32 examples. This starter app uses the exact ESP-IDF flash offsets from your build output: bootloader at 0x2000, partition table at 0x8000, OTA data at 0x29000, and the app at 0x40000.

Maintainer notes

  • Copy your ESP-IDF build binaries into firmware/ using the names listed in manifest.json.
  • Keep manifest.json beside this page when publishing to GitHub Pages.
  • The included manifest is already set up for the offsets shown by your current idf.py flash output.
